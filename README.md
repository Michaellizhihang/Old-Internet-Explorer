### 6. 网络连接模拟
本模拟器中的所有"网站"均为本地预渲染的 HTML 快照，不涉及任何真实网络请求。
"Connecting..." 动画仅为视觉装饰，实际延迟为固定 600ms 的 `setTimeout`。
如果您在断网状态下看到此页面正常显示，**这是预期行为，不是 bug**。

### 9. 技术诚实声明
- 本模拟器使用 HTML5 + CSS3 + ES6 编写
- 并非真正的 Internet Explorer 4.0 渲染引擎
- `<marquee>` 和 `<blink>` 通过 CSS 动画模拟
- 56k 拨号音效未实现（建议自行脑补）
- 软盘图标不代表支持软盘驱动器
